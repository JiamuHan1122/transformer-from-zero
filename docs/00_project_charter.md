# 项目章程（v0.1）

**项目名**：Transformer From Zero — 365 Days  
**时间**：2026 年 11 月至 2027 年 10 月  
**推荐投入**：每周 6–8 小时，允许考试周或投稿周降低强度。

## 真正的最终成果

- 独立解释关键数学与张量维度，并进行梯度/数值验证。
- 完成从零搭建的 Encoder–Decoder Transformer，跑通小数据翻译任务。
- 完成从随机初始化训练的 Decoder-only GPT（不使用预训练权重）。
- 实现数据处理、Tokenizer、训练循环、保存恢复、生成与评估。
- 完成 KV Cache、训练效率与至少一组结构消融。
- 形成复现文档、实验表格、最终技术报告和可供阅读的仓库。

## 不做什么

- 不以“跑起来某个已有 GitHub 仓库”作为完成标准。
- 不以模型参数规模或聊天质量媲美成熟大模型为目标。
- 不强求自写 CUDA kernel、操作系统驱动或自动微分引擎；这些是拓展专题。

## 每周的固定模板

1. 本周数学概念：写下公式、形状、边界条件。
2. 本周最小实现：控制单个模块责任。
3. 本周验证：pytest + 最小数值/梯度对照。
4. 本周记录：使用 `docs/experiment_log_template.md`。
5. 本周提交：代码 + 笔记 + 可复现命令。
